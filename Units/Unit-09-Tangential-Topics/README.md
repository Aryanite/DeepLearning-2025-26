# Unit 09: Tangential Topics of Machine Learning and Neural Networks

## Overview

This unit explores theoretical foundations and specialized learning paradigms that complement core deep learning topics. It covers information theory, various learning algorithms, and specialized network architectures that provide deeper understanding of neural network behavior and capabilities.

5. Deep neural networks: Information theoretical perspective
6. Information bottleneck methodology

8. Capacity modelling theorems
9. Characteristics of deep neural network layers
10. Phases in double optimization
11. Encoder and decoder in DNN
12. Learning theory
13. Stochastic relation and hidden layers
14. Applying information gain

## Learning Objectives

By the end of this unit, students will be able to:

- Apply information theory concepts to understand deep learning
- Analyze neural networks from an information-theoretic perspective
- Understand the information bottleneck principle
- Implement Hebbian learning algorithms and understand their limitations
- Design and implement competitive learning networks
- Understand energy-based models and Boltzmann machines
- Work with Restricted Boltzmann Machines for unsupervised learning
- Design and implement Radial Basis Function Networks
- Compare different learning paradigms and select appropriate methods
- Apply theoretical frameworks to analyze neural network behavior
- Understand capacity theorems and their implications for deep learning
