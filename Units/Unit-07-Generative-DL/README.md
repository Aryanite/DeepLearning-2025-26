# Unit 07: Generative Deep Learning

## Overview

This unit explores generative models in deep learning, which learn to create new data samples similar to training data. It covers text generation with LSTMs, neural style transfer, variational autoencoders, and generative adversarial networks.

## Topics Covered

### Text Generation
1. Generative deep learning
2. Using LSTMs to synthesize text
3. Text synthetization procedures

### Neural Style Transfer
1. Neural style transfer and applications
2. NST working principle
3. Content and style management in NST
4. NST implementation

### Variational Autoencoders
1. Image synthesis with variational autoencoders
2. Need for image synthesis
3. Working models
4. Variational Auto Encoders (VAE)
5. Latent space

### Generative Adversarial Networks
1. Generative Adversarial Networks (GANs)
2. Generative and discriminative algorithms
3. Applications using GAN
4. GAN working principle
5. Generator and discriminator
6. Training GAN
7. Implementing GAN: 1st generation

## Learning Objectives

By the end of this unit, students will be able to:

- Understand the principles of generative modeling in deep learning
- Implement text generation using LSTM networks
- Apply neural style transfer to combine content and artistic style
- Design and train variational autoencoders for image generation
- Understand the concept of latent space in generative models
- Implement generative adversarial networks from scratch
- Distinguish between generative and discriminative models
- Train stable GAN models using appropriate techniques
- Apply generative models to creative and practical applications
- Evaluate the quality of generated samples
